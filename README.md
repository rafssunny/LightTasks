# LightTasks
A software to register daily tasks(To Do List) made in python.
I used the CustomTkinter library to build the GUI.
![print_programa](https://github.com/user-attachments/assets/874c4180-2f3c-497e-b5c1-e7a11b8d0404)

## 🛠️ Technologies used

- Language: **Python**
- Interface: **CustomTkinter**
- Messagebox: **CTkMessageBox**
- Imagens: **PIL**
- Outros: **webbrowser**

## 🚀 How to install

```bash
git clone https://github.com/rafssunny/LightTasks.git
cd LightTasks
pip install customtkinter CTkMessagebox pillow
python main.py
